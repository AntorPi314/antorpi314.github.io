## Tech Stack

This portfolio is built with React and the following tools and libraries:

- React 18 — core UI library
- Vite — build tool and development server
- Tailwind CSS — utility-first styling
- Framer Motion — animations and scroll transitions
- Lucide React — icon set

## Project Structure

```
portfolio/
  src/
    assets/       Images and static files used in the app
    components/    All React components (Navbar, Hero, Projects, etc.)
    context/       Theme (light/dark mode) context
    data/          Personal info, skills, education, and project data
    App.jsx        Main app layout
    main.jsx       App entry point
  public/          Static files served as-is (favicon, etc.)
```

## Getting Started

```bash
cd portfolio
npm install
npm run dev
```

## Build

```bash
npm run build
```

This creates a static, production-ready build inside the `dist/` folder.

## Deployment

The site is deployed on GitHub Pages using the `gh-pages` package.

```bash
npm run build
npm run deploy
```
